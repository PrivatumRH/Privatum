Verify an inference receipt

Every response from the Privatum Assistant carries digests of the prompt, the reply and the pipeline that produced it. This page recomputes them in your browser — nothing is uploaded, no request leaves this page, and it works offline. You are checking the arithmetic yourself, not taking our word for it.

or paste it

A receipt bundle contains the prompt and the response in plain text. That is what makes it checkable — SHA-256 is one-way, so a verifier holding only hashes could prove nothing. Exporting a receipt is therefore a deliberate disclosure of that one exchange.

This page bundles the same verification module the desktop app and the verify-receipt CLI run, so all three agree by construction rather than by good intentions.
